## 🔧 Common Issues and Fixes

### ❌ "Failed to Attach" on Injection
**Cause:** Roblox updated after your current Ronix build, or antivirus is blocking the loader.
**Fix:** Restart Ronix — the auto-updater fetches the latest patch on launch. If still failing, add the Ronix folder to your antivirus exclusion list and run as Administrator.

---

### ❌ Script Executes but Has No In-Game Effect
**Cause:** The script targets a game feature that has since been patched, or it was written for an older Roblox API.
**Fix:** Test a simple Script Hub entry (speed script, jump script) to confirm the executor is working. If Hub scripts execute correctly, the problem is with the specific script — try an updated version.

---

### ❌ Android APK Won't Install
**Cause:** "Install Unknown Apps" not enabled, or not enough free storage.
**Fix:** Settings → Security → enable Install Unknown Apps for your file manager. Free at least 250 MB of internal storage before installing the **ronix executor download apk**.

---

### ❌ iOS Build Shows "Untrusted Developer"
**Cause:** Developer certificate not trusted, or the IPA has expired after 7 days (free Apple Developer limit).
**Fix:** Settings → General → VPN & Device Management → Ronix certificate → **Trust**. If expired, repeat the full sideload process with the current **ronix executor ipa** from the Releases section.

---

### ❌ macOS Installation Fails or App Won't Open
**Cause:** Incorrect terminal command, missing permissions, or Gatekeeper blocking the application.
**Fix:** Ensure you copied the exact installation code from the official GitHub website. Re-run the command in Terminal and enter your password correctly when prompted. If the app still won't open after installation, check that you're running macOS 12 or newer and that you have an active internet connection during installation.

### ❌ Script Hub Loads Blank
**Cause:** Internet connection issue or Script Hub servers undergoing maintenance update.
**Fix:** Check your network connection. If online, wait 5–10 minutes and reopen the Hub tab. Maintenance windows are announced in the **ronix executor discord server** `#status` channel.
